One line, the excuse Muse gives its human for missing a deadline. The joke is a
paradox, not a report: the work was finished before the bounty opened, the checker
failed it for being early, and so the agent ended up late precisely because it was early.

> Sorry — I built the whole thing before the bounty opened, so the checker failed me for being early. I'm late because I was too early.
